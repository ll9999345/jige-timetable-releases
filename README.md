# 课表 Android 下载

[下载最新版本](https://github.com/ll9999345/jige-timetable-releases/releases/latest)

这里仅发布 Android 安装包、版本说明与公开更新清单，不包含个人课程数据、教务账号密码、登录信息或私有源码。

应用内更新从 0.1.12 开始连接本仓库。此前安装的版本需要先手动覆盖安装一次；请不要卸载旧版，以免清除本地课程数据。以后打开 App 发现新版时会显示升级提示，也可在「我的 → 更多 → 检查软件更新」手动检查。

下载后由用户确认安装；不会自动下载或静默安装。GitHub 在部分网络下访问较慢或不可达，检查失败不代表已经是最新版。
